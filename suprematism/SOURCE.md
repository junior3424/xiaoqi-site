## 2. 公有领域依据

- 作者：卡济米尔·谢韦里诺维奇·马列维奇（Kazimir Malevich），1879 年生于基辅，**1935 年 5 月 15 日逝世于列宁格勒**。
- 著作权保护期自作者逝世次年起算：
  - 中国（《著作权法》自然人作品，作者死后 50 年）→ 1986 年起进入公有领域；
  - 欧盟及多数 life+70 辖区 → 2006 年起进入公有领域；
  - 美国：1930 年前出版的作品已进入公有领域（本图录全部作品创作于 1911—1923 年）。
- 因此**作品本身**在包括中国在内的多数辖区已属公有领域，复制、展示、改编均无需授权。
- 图片文件层面：馆方与镜像站对「数字复制件」可能主张使用条款（尤其 Tate / Guggenheim 的站点条款）。本页仅作研究、教学与个人浏览之用，不对图片另行主张著作权；**二次出版请按各馆条款署明作者、作品名与馆藏号**（Tate 用 T02319，古根海姆用 76.2553.42）。

## 3. 逐幅元数据口径（页面字段 ← `manifest.json` 字段）

页面上的每一项都可回溯到源集合的 `manifest.json`（32 条数组，`n` 从 1 到 32），字段映射如下：

| 页面元素 / 属性 | manifest 字段 | 处理方式 |
|---|---|---|
| 图序（`01`…`32`） | `n` | 两位补零直出，顺序与数组一致，未重排 |
| 中文名 `h2` | `title_zh` | 逐字照抄，含括注，如「黑方块（黑色至上主义方块）」 |
| 英文名 | `title_en` | 逐字照抄，`lang="en"` |
| 年代 | `year` | 逐字照抄；第 32 幅保留原始著录「馆方记录 1911（一说 1916）」不做取舍 |
| 馆藏 | `coll` | 逐字照抄，含馆藏号 / 登录号；`馆藏未标注` 保持原文 |
| 像素 | `w` × `h` | 作为 `<img width height>` 原样写入，用于占位防抖动（CLS），不改写图片本身 |
| 图片来源站点（标签） | `src_site` | 页面上缩写为 `WikiArt` / `Tate` / `Guggenheim` 三种 |
| 来源链接 `href` | `page` | 打开馆方或镜像的**作品页**（不是图片直链） |
| 图片文件 | `file` | 去掉 `img/` 前缀后即为本页 `img/` 下的文件名 |
| 点击图片打开的原图 | `file` | 指向同目录 `img/<同一文件名>`，`target="_blank"` |
| 体积（未展示） | `bytes` | 仅用于核对复制是否完整 |

`manifest.json` 里的 `img` 字段（上游图片直链 URL）**不进入页面**：页面只引用本地 `img/`，因此在断网、`file://` 环境下同样完整可看。

## 4. 再分发说明

1. 目录 `personal-site/suprematism/` 是自包含单元：`index.html` + `img/` 拷走即可独立打开，不依赖上级目录的任何 CSS / JS / 字体文件（字体走系统回退，联网时再取 Jost / Noto Sans SC / IBM Plex Mono）。
2. 唯一的外链是每幅的「来源」作品页，以及页头 / 页脚的站内回链 `../index.html#index`。回链在脱离个人站单独分发时会 404，属预期。
3. 图片不得改名或重压缩后再声称与本图录一致；如需替换为更高清版本，直接以**同名文件覆盖** `img/` 内对应文件，页面无需改动（`width`/`height` 属性随之更新为该图真实像素）。
4. 若下游需要重新采集，按 `projects/malevich_suprematism/manifest.json` 的 `page` 字段逐条回访，字段名与上表一致即可原样落回本页。
